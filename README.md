# Network & Cloud Infrastructure Engineer Portfolio

A sleek, responsive portfolio website built for **Network & Cloud Infrastructure Engineers**.

## 🌟 Structure & Features

1. **Hero Section**:
   - Availability status indicator badge.
   - Headline and background bio.
   - Quick statistics counter strip (`99.999% SLA Uptime`, `40+ Gbps`, `1,200+ Automated Ports`, `8+ Yrs Experience`).
   - "Get in Touch" primary call to action.

2. **Light & Dark Cyber/Cloud Theme**:
   - Cyber cyan and dark slate theme with glowing accents.
   - High-contrast clean light theme.
   - Preserves theme choice in `localStorage`.

3. **Contact & Direct Channels**:
   - Direct communication channels with one-click copy to clipboard buttons (Email, LinkedIn, GitHub, Location & Timezone).
   - Working contact message form with submit feedback.

4. **Footer**:
   - Clean footer with overview link, contact link, and back-to-top button.

## 🚀 How to Run or Host

- **To preview locally**: Double-click `index.html` in any web browser.
- **To publish**: Drag and drop this folder directly into GitHub Pages, Netlify, Vercel, or any standard hosting provider.
